# Admin AI Assistant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an agentic Admin AI chat page at `/admin/ai` reusing the public AI tab stack, backed by a new admin-only chat API route with read + allowlisted write tools.

**Architecture:** New zod schemas in `lib/schemas.ts`; new `POST /api/admin/chat/route.ts` (mirrors `app/api/chat/route.ts` but with `withAdminAuth` and admin tools calling `services/` directly); new `app/admin/ai/` page reusing `ai-elements/`; additive admin branches in `ToolResultCards`; one sidebar nav line.

**Tech Stack:** Next.js 16 App Router, React 19, AI SDK v6 (`ai`, `@ai-sdk/react`, `@ai-sdk/openai-compatible`), zod v4, React Query v5, drizzle-orm, vitest.

**Spec:** `docs/superpowers/specs/2026-10-14-admin-ai-design.md`

## Global Constraints

- No `export default` in non-page files; `page.tsx` files must use `export default`.
- `"use client"` at the top of any component using hooks, state, or browser APIs.
- Zero raw `fetch`/`api()` in admin page files; card Apply-actions use typed `adminApi` methods only.
- All API error responses use `{ error: { message, code } }` shape.
- Every `catch {}` must call `logger.error`; no silent catches.
- No comments unless explaining a non-obvious workaround.
- Imports grouped external → internal with `@/` alias; kebab-case files, `memo()` for list-rendered components, `useCallback` for handlers passed to memo'd children.
- `npm run typecheck` (`tsc --noEmit`) and `npm test` (`vitest run`) must pass.

- [ ] **Step 4: Add the POST handler with admin auth, rate limit, and streaming**

Append to the same file:

```ts
export const POST = withAdminAuth(async (req, { session }) => {
  const { allowed } = await rateLimit(`admin-chat:${session.user.id}`, RATE_LIMITS.adminChat);
  if (!allowed) return rateLimitResponse();

  const body = await req.json();
  const parsed = chatApiSchema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json(
      { error: { message: "Validation failed", code: ErrorCode.ValidationError } },
      { status: 400 }
    );
  }
  const { messages, model } = parsed.data;

  const result = streamText({
    model: kilocode.languageModel(model || "kilo-auto/free"),
    system: `You are the Streamflix Studio admin assistant. You help admins triage reports and requests, enrich the catalog with tags, and answer analytics questions.

Tool results render as cards in the UI automatically — just acknowledge them naturally.

**Rules:**
- Keep responses concise and operational
- Always cite report, request, and movie IDs when referring to them
- Use listPendingReports for moderation triage, listPendingRequests for the request queue
- Use searchCatalog to find a movie's internal ID, then suggestTags to recommend tags
- Use getDashboardStats, getRecentSignups, and getMostFavorited for analytics questions
- Never use markdown image syntax — the UI handles rendering automatically`,
    messages: await convertToModelMessages(messages as UIMessage[]),
    tools: { ...readTools },
    stopWhen: [stepCountIs(3)],
  });

  return result.toUIMessageStreamResponse();
});
```

- [ ] **Step 2: Add the four write tools before the POST handler**

```ts
const writeTools: ToolSet = {
  resolveReport: {
    description:
      "Set a report's status to pending or resolved. Use after the admin confirms which report to action.",
    inputSchema: adminChatResolveReportSchema,
    execute: async ({ id, status }: { id: number; status: "pending" | "resolved" }) => {
      try {
        const result = await updateReportStatus(id, status);
        if ("error" in result) return result;
        await invalidateCache("reports");
        return { ok: true, id, status, invalidatedKeys: ["admin-reports"] };
      } catch (err) {
        return toolFailure("resolveReport", err);
      }
    },
  },
  fulfillRequest: {
    description:
      "Mark a movie request as fulfilled. Use after the admin confirms which request is done.",
    inputSchema: adminChatFulfillRequestSchema,
    execute: async ({ id }: { id: number }) => {
      try {
        const result = await fulfillRequest(id);
        if ("error" in result) return result;
        await invalidateCache("requests");
        return { ok: true, id, invalidatedKeys: ["admin-requests"] };
      } catch (err) {
        return toolFailure("fulfillRequest", err);
      }
    },
  },
  assignTags: {
    description:
      "Replace a movie's tags with the given tag IDs. Use after the admin confirms the tag picks.",
    inputSchema: adminChatAssignTagsSchema,
    execute: async ({ movieId, tagIds }: { movieId: number; tagIds: number[] }) => {
      try {
        const updated = await updateMovie(movieId, { tagIds });
        if (!updated) return { error: "Movie not found" };
        return { ok: true, movieId, tagIds, invalidatedKeys: ["admin-movies", "admin-tags"] };
      } catch (err) {
        return toolFailure("assignTags", err);
      }
    },
  },
  importTmdbMovie: {
    description:
      "Create a new unpublished catalog movie from a TMDB ID, using TMDB metadata. Use after the admin confirms the TMDB pick.",
    inputSchema: adminChatTmdbIdSchema,
    execute: async ({ tmdbId }: { tmdbId: number }) => {
      try {
        const d = await getTMDBMovieDetails(tmdbId);
        const trailerUrl = await getTMDBMovieTrailer(tmdbId);
        const slug = d.title
          .toLowerCase()
          .replace(/[^a-z0-9]+/g, "-")
          .replace(/(^-|-$)/g, "");
        const movie = await createMovie({
          title: d.title,
          slug,
          description: d.overview,
          releaseDate: d.release_date,
          originalLanguage: d.original_language,
          tmdbId,
          durationSeconds: d.runtimeMinutes ? d.runtimeMinutes * 60 : null,
          thumbnailUrl: tmdbImageUrl(d.poster_path) ?? "",
          backdropUrl: tmdbImageUrl(d.backdrop_path, "w1280"),
          trailerUrl,
        });
        return { ok: true, movieId: movie.id, slug, invalidatedKeys: ["admin-movies", "admin-stats"] };
      } catch (err) {
        return toolFailure("importTmdbMovie", err);
      }
    },
  },
};
```

Implementation notes the executor must preserve: `updateMovie` and `createMovie` already call `invalidateMovieCaches()` internally; the extra `invalidateCache("reports")` / `invalidateCache("reports")`-scope calls cover the Redis list caches those two services do not touch. `createMovie` sets `published: false`, so imports are always drafts. No delete tool exists by design.

```ts
import { useState } from "react";
import { useChat } from "@ai-sdk/react";

export function useAdminChat() {
  const [input, setInput] = useState("");

    messages: chat.messages,
```

```tsx
      <div>
        <h1 className="text-3xl font-bold font-heading tracking-tight">AI Assistant</h1>
        <p className="text-muted-foreground mt-1">Triage, enrich, and analyze your catalog.</p>
      </div>
      <Conversation>
        <ConversationContent>
          {error && !errorDismissed && (
            <div className="mx-auto flex max-w-sm items-center gap-3 rounded-lg border border-destructive/50 bg-destructive/10 px-4 py-3 text-sm text-destructive">
              <AlertTriangle className="size-4 shrink-0" />
              <p className="flex-1">{getFriendlyError(error)}</p>
              <Button
                variant="ghost"
                size="icon-sm"
                onClick={() => setErrorDismissed(true)}
              >
                <XIcon className="size-3" />
              </Button>
            </div>
          )}
          {messages.length === 0 ? (
            <div className="flex flex-col items-center gap-6">
              <ConversationEmptyState
                icon={
                  <Image
                    src="/favicon.svg"
                    alt="StreamFlix Studio Logo"
                    width={48}
                    height={48}
                    className="size-12"
                  />
                }
                title="Streamflix Studio AI"
                description="Triage reports, enrich the catalog, or ask about site metrics"
              />
              <Suggestions>
                {ADMIN_CHAT_SUGGESTIONS.map((suggestion) => (
                  <Suggestion
                    key={suggestion}
                    suggestion={suggestion}
                    onClick={handleSuggestionClick}
                  />
                ))}
              </Suggestions>
            </div>
          ) : (
            <div className="flex flex-col gap-3">
              {messages.map((message, messageIndex) => (
                <Fragment key={message.id}>
                  {message.parts.map((part, i) => {
                    if (part.type === "text") {
                      return (
                        <Fragment key={`${message.id}-${i}`}>
                          <Message from={message.role}>
                            <MessageContent>
                              <MessageResponse>{part.text}</MessageResponse>
                            </MessageContent>
                          </Message>
                          {message.role === "assistant" &&
                            messageIndex === messages.length - 1 && (
                              <MessageActions>
                                <MessageAction
                                  onClick={handleRetry}
                                  label="Retry"
                                >
                                  <RefreshCcwIcon className="size-3" />
                                </MessageAction>
                              </MessageActions>
                            )}
                        </Fragment>
                      );
                    }

                    if (part.type === "step-start") {
                      return null;
                    }

                    if (part.type.startsWith("tool-") || part.type === "dynamic-tool") {
                      const toolPart = part as unknown as ToolPart;
                      const isInProgress = toolPart.state === "input-streaming" || toolPart.state === "input-available";
                      const isError = toolPart.state === "output-error";

                      if (isInProgress || isError) {
                        return (
                          <ToolCallIndicator
                            key={`${message.id}-${i}`}
                            part={toolPart}
                          />
                        );
                      }

                      if (toolPart.state === "output-available") {
                        const toolName = toolPart.toolName ?? part.type.replace("tool-", "").replace(/-/g, " ");
                        return (
                          <ToolResultCards
                            key={`${message.id}-${i}`}
                            toolName={toolName}
                            output={toolPart.output}
                          />
                        );
                      }

                      return null;
                    }

                    return null;
                  })}
                </Fragment>
              ))}
              {status === "submitted" && (
                <Message from="assistant">
                  <MessageContent>
                    <div className="flex items-center gap-2 text-muted-foreground text-sm">
                      <Loader2 className="size-4 animate-spin" />
                      <span>Thinking...</span>
                    </div>
                  </MessageContent>
                </Message>
              )}
            </div>
          )}
        </ConversationContent>
        <ConversationScrollButton />
      </Conversation>

      <PromptInput
        onSubmit={handleSubmit}
        className="mx-auto w-full p-4"
      >
        <PromptInputTextarea
          className="min-h-10"
          value={input}
          placeholder="Ask about reports, requests, tags, or metrics..."
          onChange={(e) => setInput(e.currentTarget.value)}
        />
        <PromptInputSubmit
          className="mr-1 shrink-0 rounded-md"
          status={status === "streaming" ? "streaming" : "ready"}
          disabled={!input.trim()}
        />
      </PromptInput>
    </div>
  );
}
```

```tsx
  movieId: number;
  current: { id: number; name: string }[];
  available: { id: number; name: string }[];
```
