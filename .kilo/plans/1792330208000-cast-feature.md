# Plan: Cast / People Feature (TMDB-style cast & crew)

## Goal
Add TMDB-style people + movie credits: People table, movie_credits junction (cast/crew, role, character, order), idempotent TMDB backfill, admin management, and client-facing cast display on movie detail pages.

## Resolved design decisions
- Cast/crew displayed on movie detail page.
- Backfill targets published movies with a `tmdbId`, paginated, default limit 50, rate-limit-aware via existing `fetchWithRetry`.
- Person profile image stored as external TMDB `profile_url` (no re-upload).
- Movie import does NOT auto-import cast; separate "Import cast from TMDB" action on movie edit page.

## Data flow
`TMDB /movie/{id}/credits` → `services/people.ts:importCreditsForMovie` upserts `people` (on `tmdbId` conflict update) + `movie_credits` (on `(movieId, personId, roleType)` conflict do nothing) → admin API `POST /api/admin/backfill/cast` → React Query invalidation → client detail page reads credits.
