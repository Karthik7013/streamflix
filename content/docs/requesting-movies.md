## When to make a request

If you can't find a movie in the catalog, you can submit a request from the "Request a Movie" page. StreamFlix reviews requests and adds titles when possible.

## What to fill in

The request form has three fields:

- Movie title — required
- Description — optional; a sentence about the movie helps
- External link — optional; for example, an IMDB page for the film

## Requirements and what happens next

Signing in is required to submit a request — if you're signed out, you'll be redirected to log in first. After you submit, the request lands in a queue that administrators review. There's no set timeline, but if the title is added it appears in the catalog for everyone.
